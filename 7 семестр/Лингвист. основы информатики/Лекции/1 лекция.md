## 3. Языки программирования и их применение

Выбор языка зависит от **предметной области**.

| Область применения | Основные языки | Другие языки |
|---|---|---|
| Обработка деловой информации | COBOL, spreadsheet | C, Java, Pascal, PL/1, 4GLs |
| Научные вычисления | FORTRAN, C, C++, Object Pascal, Java | Pascal, BASIC |
| Системная область | C, C++, Object Pascal, Java | Pascal, BASIC, C# |
| Искусственный интеллект | LISP, Prolog | — |
| Издательская деятельность | TeX, Postscript, текстовые процессоры | — |
| Создание процессов | Shell, JSP, Perl, JavaScript, C# | PHP, AWK, Marvel, SED |

> [!note] Пояснения
> - **COBOL**, **FORTRAN** — исторически первые языки для бизнеса и науки.
> - **LISP**, **Prolog** — декларативная и логическая парадигмы, применяются в ИИ.
> - **TeX**, **Postscript** — специализированные языки вёрстки и печати.
> - **Shell**, **Perl**, **JavaScript** — автоматизация и веб-разработка.

## 4. Свойства хорошего языка программирования

1. **Ясность, простота и единообразие понятий**
2. **Гибкость, ортогональность**
3. **Надёжность и удобство верификации**
4. **Естественность и поддержка абстракций**
5. **Среда программирования**
6. **Мобильность программ**
7. **Стоимость:**
   - стоимость обучения языку
   - стоимость реализации программы
   - стоимость трансляции программы
   - стоимость выполнения программы
   - стоимость сопровождения программы

> [!important] Ортогональность
> Комбинация возможностей языка не порождает неожиданных эффектов. Если операция определена для нескольких типов, она должна работать единообразно во всех контекстах.

## 5. Синтаксис и семантика

| Понятие | Определение | Пример |
|---|---|---|
| **Синтаксис** | Как выглядит программа: правила построения конструкций | `if (x > 0) { ... }` в C++ |
| **Семантика** | Смысл конструкций: что они означают при выполнении | Проверка условия и выполнение блока при истинности |

> [!warning] Важно
> Синтаксически корректная программа может быть семантически бессмысленной (деление на ноль, обращение к несуществующей переменной).

## 6. Парадигмы языков программирования

- **Императивные** — последовательность инструкций, изменяющих состояние *(C, Pascal, Fortran)*
- **Аппликативные** — вычисление как применение функций *(Lisp, Haskell)*
- **Декларативные** — описание результата без указания способа *(Prolog, SQL)*
- **Объектно-ориентированные** — объекты, инкапсулирующие данные и методы *(C++, Java, Python)*

> [!note] Мультипарадигменность
> Современные языки часто поддерживают несколько парадигм. Например, Python — императивный, ООП и функциональный.

## 7. Итоги лекции

- Курс: от формальных грамматик до компиляторов.
- Языки выбираются под задачи; хороший язык — ясный, надёжный, мобильный, экономичный.
- Ключевые понятия: **синтаксис** (форма) и **семантика** (смысл).
- Основные парадигмы: императивная, аппликативная, декларативная, объектно-ориентированная.
