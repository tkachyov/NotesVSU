# 📚 Лекция 1: Введение в операционные системы

> [!info] Основная информация
> **Дата занятия:** 04.09.2026
> **Тема:** Введение. Предпосылки создания, история развития и базовые концепции ОС.

---

## 1. 🎯 Зачем нужна операционная система?

> [!abstract] Определение
> ОС — это комплекс программ, который управляет аппаратным обеспечением и предоставляет среду для работы прикладных программ.

**Основные задачи ОС:**

- ⚙️ **Многозадачность и распределение ресурсов:** Управление задачами, их изоляция и взаимодействие.
- 🧩 **Абстракция аппаратуры:** Создание удобных виртуальных объектов ([[Файл]], [[Процесс]], [[Семафор]], [[Событие]], [[Очередь]]), скрывающих детали «железа».
- 🔌 **Абстрактный ввод-вывод:** Независимость от конкретных аппаратных реализаций (например, файлы устройств).
- 🖥️ **Пользовательский интерфейс:** CLI (Command Line Interface), GUI.
- 🚀 **Инициализация:** Запуск и проверка аппаратной платформы при включении.

### 🔹 Уровни абстракции

| Уровень | Описание |
| :--- | :--- |
| **API (Application Programming Interface)** | Прикладные программы общаются с ОС. Работа с файлами, синхронизация, распределение памяти и процессора. |
| **HW (Hardware)** | ОС напрямую управляет железом: чтение/запись ячеек памяти, дисковых блоков, выполнение операций процессором, обработка прерываний. |

> [!warning] Bare Metal Programming
> Разработка программ **без** использования API операционной системы (напрямую на железе).
> - **Плюсы:** Максимальная производительность.
> - **Минусы:** Сложность, отсутствие защиты.
> - *Использование:* Критичные ко времени задачи (embedded-системы).

## 2. 🏛️ Предпосылки создания ОС

### Чарльз Бэббидж (Charles Babbage)
- **1833 г.:** Разработал проект первой универсальной цифровой вычислительной машины («Процессор»).
- *Примечание:* Опередил время, но не был построен из-за отсутствия технологий.

### Ада Лавлейс (Ada Lovelace)
- **1843 г.:** Составила первую программу для машины Бэббиджа.
- Ввела термины **«цикл»** и **«переменная»**.
- Считается первым программистом. В честь неё назван язык **Ada**.

## 3. ⚙️ Эволюция вычислительных систем

### Механические компьютеры (Ascota 170)
- **Программирование:** 50 шагов программы, 56 регистров по 12 разрядов.
- **Особенности:** Программирование вручную (переключателями).

### ENIAC (1945)
- Первая программируемая цифровая ЭВМ общего назначения.
- **Характеристики:** 30 тонн, 174 кВт, 17468 ламп, память — 20 чисел.
- **Особенность:** Программа не хранилась в памяти, а задавалась коммутацией электрических цепей.

### IBM-701 и первая ОС (1952–1955)
- **IBM-701:** Первый коммерческий компьютер для научных расчетов.
- **GMOS (1955):** Первая в мире операционная система (General Motors для IBM-701).
    - Реализовала **пакетный режим (batch)** вычислений.

## 4. 🔄 Развитие многозадачности и памяти

### Пакетная обработка (Batch Processing)
- **Однозадачный режим:** Медленные устройства ввода-вывода (перфокарты, принтеры) простаивали, пока «Большая ЭВМ» считала.
- **Система пакетной обработки:** Введение малых ЭВМ (сателлитов) для буферизации ввода-вывода.
- **Расширенная система:** Добавление устройств хранения на магнитных барабанах для загрузки библиотек.

### Многозадачность (TSS — Time-Sharing System)
- **Идея:** Загрузка нескольких программ в память одновременно.
- **Механизм:** Пока одна программа ждет завершения ввода-вывода, процессор переключается на другую задачу.

> [!danger] Проблемы реализации многозадачности
> 1. Защита кода и данных ОС от программ.
> 2. Изоляция программ друг от друга.
> 3. Бесконфликтное разделение ресурсов.
> 4. Эффективное использование памяти.
> 5. Разделение процессорного времени.

## 5. 🧠 Проблемы управления памятью

### Проблема защиты памяти
- **Граничный регистр:** Аппаратный регистр, запрещающий программам обращаться к памяти за его пределами (защита ОС).
- *Ограничение:* Решает проблему защиты ОС, но не решает проблему изоляции программ (решено позже в [[Виртуальная память|виртуальной памяти]]).

### Проблема эффективного использования памяти
- **Фрагментация:** Даже если общий объем свободной памяти достаточен, она может быть разбита на куски, и программа не может быть загружена.
- **Свопинг (Swapping):** Перемещение неактивных программ из ОЗУ во вторичную память.
    - Реализован в начале 60-х.
    - Позже получил аппаратную поддержку в виде **страничного механизма (paging)**.

### Виртуальная память
- **ВАП (Виртуальное Адресное Пространство):** Для каждого процесса формируется собственное адресное пространство.
- **Трансляция адресов:** Замена виртуального адреса (выставленного программой) на физический адрес в ОЗУ.
- **Первая реализация:** Компьютер **Atlas** (Манчестерский университет, 1962).
    - ОЗУ: 16К слов, Вторичная память: 96К слов, ВАП: 2М слов.
- **Преимущества:** Решает проблемы защиты, изоляции, фрагментации и взаимодействия параллельных программ.
- **Распространение:** К середине 1990-х стала повсеместной, включая ПК.

## 6. 🐧 История UNIX

### Предыстория
- **BESYS (1957):** ОС от Bell Labs для IBM-704.
- **Multics (1964–1969):** Совместный проект MIT, General Electric и Bell Labs.
    - **Инновации:** Централизованная файловая система (дерево каталогов), виртуальная память с сегментно-страничной организацией, отображение файлов на адресное пространство.
    - **Безопасность:** В 1985 году сертифицирован по классу B2.
    - **Закат:** Bell Labs вышла из проекта в 1969 году.

### Появление UNIX (1969–1970)
- **Кен Томпсон, Деннис Ритчи, Дуглас Макилрой, Джозеф Оссанна** (Bell Labs) продолжили работу над ОС для DEC PDP-7.
- **1969:** Томпсон реализовал самодостаточную ОС с ассемблером, редактором и командным интерпретатором (shell).
- **Название:** Брайан Керниган предложил **Unics** (Uniplexed Information and Computing Service) по аналогии с Multics. Позже трансформировалось в **Unix**.
- **1970:** Перенос на PDP-11, добавлена поддержка текстовых документов (roff).
- **3 ноября 1971:** Выпущена первая редакция документации (официальное появление Unix).

### Развитие и стандартизация
- **1972 (v2):** Программные каналы (pipes), компилятор C.
- **1973 (v4):** Первая версия, написанная на C.
- **1975 (v6):** Первая коммерческая версия, доступная за пределами Bell Labs.
- **1976:** Группа в Университете Беркли основала ветвь **BSD UNIX** (Berkeley Software Distribution).
    - Внесли: редактор vi, стек TCP/IP, страничный механизм виртуальной памяти, файловая система FFS.
    - Легла в основу macOS, SunOS, FreeBSD, NetBSD.
- **1978–1989:** AT&T создает подразделение USG (Unix Support Group).
    - **System III (1982):** Именованные программные каналы.
    - **System V (1983):** Семафоры, разделение памяти, очереди сообщений.
    - **SVR4 (1989):** Последняя версия UNIX от AT&T.

### Стандарт POSIX
- **POSIX (Portable Operating System Interface):** Стандарт, обеспечивающий совместимость прикладных программ.
- **POSIX.1 (1988):** Первый документ, стандартизирующий API UNIX-совместимых систем.
- Регламентирует языки программирования, библиотеки, утилиты и пользовательские интерфейсы.

### Проект GNU (1983)
- **Основатель:** Ричард Столлман (Richard Stallman).
- **Цель:** Создание свободной UNIX-подобной ОС без использования оригинального кода.
- **GNU (GNU's Not UNIX):** Рекурсивный акроним.
- **Компоненты:** GNU toolchain, Glibc, Coreutils.
- **Ядро:** Проект **HURD** (HIRD of Unix-Replacing Daemons) до сих пор не завершен.

## 7. 🪟 Предыстория Windows

- **Microsoft (1975):** Основана Биллом Гейтсом и Полом Алленом для разработки интерпретатора BASIC для Altair 8800.
- **1980:** Выход на рынок ОС с лицензированной версией UNIX под маркой **Xenix**.
- **1980 (Ноябрь):** Контракт с IBM на разработку аналога CP/M для IBM PC.
- **MS-DOS:** Microsoft выкупила 86-DOS у Seattle Computer Products, доработала и переименовала.
    - Структура команд повторяла CP/M (Digital Research), что упростило перенос программ.
- **1981 (Август):** Выход IBM PC с PC DOS (позже MS-DOS).
- **1985:** Выход Windows 1.0 (графическая оболочка для MS-DOS).
    - *Контекст:* Толчком послужили Visi On (1983), TopView (IBM) и DESQview (Quarterdeck).
