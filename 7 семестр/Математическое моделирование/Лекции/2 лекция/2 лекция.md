> [!warning] Метод Фостера-Стюарта (помогает ваявить наличие/отсутствие тренда)
>
Этот метод может быть реализован следующей последовательностью шагов:
>
>1) Каждый уровень ряда сравнивается со всеми предыдущими уровнями, при этом определяются значения вспомогательных характеристик $m_t, l_t$.
>$$m_t = \begin{cases} 
1, y_t > y_{t-1}, y_{t-2}, ..., y_{1}\\
0, \text{в противном случае} \\ 
\end{cases} $$
>$$l_t = \begin{cases} 
1, y_t < y_{t-1}, y_{t-2}, ..., y_{1}\\
0, \text{в противном случае} \\ 
\end{cases} $$
>2) Вычисляется величина $d_t = m_t - l_t, t = \overline{2,N}$.
>	Очевидно, что $d_t$ может принимать значения $1, -1, 0$.
>
>3) Находится характеристика $D = \sum_{t=2}^N d_t$.
>
>4) С помощью критерия Стьюдента проверяется гипотеза о том, что можно считать случайной разность $D - 0$ (то есть ряд может считаться случайным, не содержащим тренд), для этого определяется величина $t_{набл} = \frac{D}{\sigma_D}$, где $\sigma_D$ - квадратичная ошибка $D$. 
>
>5) Расчётное значение $t_{набл}$ сравнивается с критическим значением $t_{кр}$, взятого из таблицы распределения Стьюдента с доверительной вероятностью $\alpha$ и количеством степеней свободы $\nu = N - 1$. 
>	Если $|t_{набл}| > t_{кр}$, то гипотеза об отсутствии тренда отвергается.


> [!note] Есть и другие критерии, которые отличаются друг от друга мощностью, сложностью математического аппарата, например: 
>- критерий Аббе;
>- метод проверки разности средних уровней;
>- критерий серий.

#### Сглаживание и фильтрация временных рядов

##### Применение простых скользящих средних

Распространённым приёмом при выявлении и анализе тенденции развития является сглаживание временного ряда.

Суть различных приёмов сглаживания сводится к замене фактических уровней временного ряда расчётными уровнями, которые в меньшей степени подвержены колебаниям.

Методы сглаживания условно делятся на 2 класса:
1) Аналитический подход
2) Алгоритмический подход


Алгоритм сглаживания по простому скользящему среднему может быть представлен в виде следующей  последовательности шагов:

1) Определяем длину интервала сглаживания $l$, включающего в себя $l$ последовательных уровней ряда $(l < N)$. При этом имеем ввиду, что чем шире интервал сглаживания, тем в большей степени взаимопогашаются колебания.

2) Разбиваем весь период наблюдения на участки, при этом интервал сглаживания как бы скользит по ряду с шагом, равным одному.

3) Рассчитываем средние арифметические, образующие каждый участок.

4) Заменяем фактические значения временного ряда, стоящие в центре каждого участка, на соответствующие средние значения.


Обычно, удобно брать длину интервала сглаживания $l$ в виде нечётного числа $(i = 2p + 1, p \in N)$.
В этом случае  значения скользящей средней приходятся на средний члени ряда.

Наблюдения, которые берутся для расчёта среднего значения называются активным участком сглаживания.

При нечётном значении $l$ уровни активного. участка могут быть представлены в виде:

$$y_{t-p}, y_{t-p+1}, ..., y_{t-1}, y_t, y_{t+1}, ..., y_{t+p-1}, y_{t+p}$$
$y_t$ - центральный уровень активного участка.

$$\hat{y_t} = \frac{\sum_{i = t-p}^{t+p} y_i}{2p + 1}$$

Если у нас есть периодические или сезонные колебания, то удобно брать длину интервала сглаживания, равную или кратную периоду колебаний.

Тогда формула для скользящей средней рассчитывается следующим образом:
$$\hat{y_t} = \frac{\frac{1}{2} y_{t-p} + \sum_{i = t - p + 1}^{t + p-1} y_i + \frac{1}{2} y_{t + p}}{2p}$$
