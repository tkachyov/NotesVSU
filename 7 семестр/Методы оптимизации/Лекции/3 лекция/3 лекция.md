#### Симплекс-таблица

Пусть дана задача $(1) - (3)$ и в системе ограничений $(2)$ имеет $r$ базисных неизвестных $x_1, x_2, ..., x_r$.

$$ \begin{cases} 
x_1 + a_{1, r + 1} x_{r + 1} + ... + a_{1j}x_j + ... + a_{1n} x_n = b_1\\
...\\
x_i + a_{i, r + 1} x_{r + 1} + ... + a_{ij} x_j + ... + a_{in} x_n = b_i \\
...\\
x_r + a_{r, r + 1} x_{r + 1} + ... + a_{rj} x_j + ... + a_{rn} x_n = b_r \\
\end{cases} $$


Целевая функция, выраженная через свободную переменные:
$$z = \gamma_{r + 1} x_{r + 1} + \gamma_{r + 2} x_{r + 2} + ... + \gamma_{n} x_{n} + \gamma_0 \tag{*}$$

Выражение $(*)$ перепишем в виде:
$$z - \gamma_{r + 1} x_{r + 1} - \gamma_{r + 2} x_{r + 2} - ... - \gamma_{n} x_{n} = \gamma_0$$

Данные из полученных записей перенесём в симплекс-таблицу.

| Базис | $x_1$ | ... | $x_i$ | ... | $x_r$ |    $x_{r + 1}$     | ... |    $x_j$     | ... |    $x_n$     |  Решение   |
| :---: | :---: | :-: | :---: | :-: | :---: | :----------------: | :-: | :----------: | :-: | :----------: | :--------: |
| $x_1$ |   1   | ... |   0   | ... |   0   |   $a_{1, r + 1}$   | ... |   $a_{1j}$   | ... |   $a_{1n}$   |   $b_1$    |
|  ...  |  ...  | ... |  ...  | ... |  ...  |        ...         | ... |     ...      | ... |     ...      |    ...     |
| $x_i$ |   0   | ... |   1   | ... |   0   |   $a_{i, r + 1}$   | ... |   $a_{ij}$   | ... |   $a_{in}$   |   $b_i$    |
|  ...  |  ...  | ... |  ...  | ... |  ...  |        ...         | ... |     ...      | ... |     ...      |    ...     |
| $x_r$ |   0   | ... |   0   | ... |   1   |   $a_{r, r + 1}$   | ... |   $a_{rj}$   | ... |   $a_{rn}$   |   $b_r$    |
|   z   |   0   | ... |   0   | ... |   0   | $- \gamma_{r + 1}$ | ... | $- \gamma_j$ | ... | $- \gamma_n$ | $\gamma_0$ |


#### Алгоритм симплекс-метода

1. Привести задачу линейного программирования к каноническому виду.
2. Найти начальное допустимое базисное решение.
3. Составить симплекс- таблицу.
4. Выбор переменной, вводимой в базис.
	
	Условие оптимальности:
	В задачах максимизации (минимизации) в базис вводится переменная, имеющая наибольший по модулю отрицательный (положительный) коэффициент в $z$ строке симплекс-таблицы.

	Столбец симплекс-таблицы, соответствующий вводимой в базис переменной называется ведущим столбцом.

5. Выбор переменной, выводимой из базиса.

	Условие допустимости:
	И в задаче максимизации, и в задаче минимизации из базиса исключается переменная, которой соответствует минимальное отношение числа, стоящего в столбце "Решение" таблицы к положительному элементу ведущего столбца.
	Если таких переменных несколько, то выбирается любая из них.

	Строка, соответствующая исключаемой из базиса переменной называется ведущей строкой.

	Элемент, стоящий на пересечении ведущей строки и ведущего столбца называется ведущим элементом.

6. Переход к новому базисному решению (новой таблицы).

	Пересчёт элементов таблицы осуществляется по следующим правилам:
	1) Элементы строки, соответствующей вводимой в базис переменной, получаются делением элементов ведещей строки на ведущий элемент.
	2) Элементы оставшихся строк, включая $z$ строку, вычисляются следующим образом:
		- (новая строка) = (старая строка) - (коэффициент, соответствующий этой строке в ведущем столбце) $\cdot$ (строка, полученная на месте ведущей).



##### Пример.

$$\begin{cases} 
z = 3x_1 + 2x_2 \rightarrow max\\ 
x_1 + x_2 \le 4 \\ 
2x_1 + x_2 \le 6 \\ 
x_1, x_2 \ge 0 
\end{cases}$$

$$\begin{cases} 
z = 3x_1 + 2x_2 + 0x_3 + 0x_4 \rightarrow max\\ 
x_1 + x_2 + x_3 = 4 \\ 
2x_1 + x_2 + x_4 = 6 \\ 
x_1, x_2, x_3, x_4 \ge 0 
\end{cases}$$

$$z - 3 x_1 - 2x_2 + 0x_3 + 0x_4 = 0$$


| Базис | $x_1$ | $x_2$ | $x_3$ | $x_4$ | Решение |
| ----- | ----- | ----- | ----- | ----- | ------- |
| $x_3$ | 1     | 1     | 1     | 0     | 4       |
| $x_4$ | 2     | 1     | 0     | 1     | 6       |
| z     | -3    | -2    | 0     | 0     | 0       |

Выбираем ведущим столбец $x_1$, так как в $z$ строке наибольший по модулю отрицательный элемент (-3).

4:1 = 4
6:2 = 3 (min)

Следовательно, строка $x_4$ ведущая.


| Базис | $x_1$ | $x_2$ | $x_3$ | $x_4$ | Решение |
| ----- | ----- | ----- | ----- | ----- | ------- |
| $x_3$ | 0     | 1/2   | 1     | -1/2  | 1       |
| $x_1$ | 1     | 1/2   | 0     | 1/2   | 3       |
| z     | 0     | -1/2  | 0     | 3/2   | 9       |

$x_1: (2, 1, 0, 1, 6) : 2$
$x_3: (1, 1, 1, 0, 4) - (1) \cdot (1, 1/2, 0, 1/2, 3)$
$z: (-3, -2, 0, 0, 0) - (-3) \cdot (1, 1/2, 0, 1/2, 3)$

Столбец $x_2$ - ведущий, так как $-1/2$.
1:$\frac{1}{2}$ = 2 (min)
3:$\frac{1}{2}$ = 6

Следовательно, строка $x_3$ ведущая.

| Базис | $x_1$ | $x_2$ | $x_3$ | $x_4$ | Решение |
| ----- | ----- | ----- | ----- | ----- | ------- |
| $x_2$ | 0     | 1     | 2     | -1    | 2       |
| $x_1$ | 1     | 0     | -1    | 1     | 2       |
| z     | 0     | 0     | 1     | 1     | 10      |
$x_2: (0, 1/2, 1, -1/2, 1) : 1/2$
$x_1: (1, 1/2, 0, 1/2, 3) - 1/2 \cdot (0, 1, 2, -1, 2)$
$z: (0, -1/2, 0, 3/2, 9) - (-1/2) \cdot (0, 1, 2, -1, 2)$


Ответ: $$x^*_1 = 2$$$$x^*_2 = 2$$
$$z^* = 10$$
