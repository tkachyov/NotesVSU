Среди кривых роста первого типа обычно выделяют класс полиномов.
$$\hat{y}(t) = a_0 + a_1 t + a_2 t^2 + ... + a_n t^n$$
Коэффициенты полиномов невысоких степеней могут иметь конкретную интерпритацию в зависимости от содержания динамического ряда.

Например, при $t=0:a_0$ - интерпретируется как начальный уровень ряда;
$a_1$ - как скорость роста; $a_2$ - ускорение роста; $a_3$ - изменение ускорения.

$$\sum_{k=1}^n (y_t - \hat{y}_t)^2 \underset{\bar{a}}{\rightarrow} min$$
Также к первому классу относится показательная кривая ($\hat{y}_t = ab^t$)

Для того, чтобы найти параметры такой модели, нужно её прологарифмировать и применить МНК.

Ко второму классу относится модифицированная экспонента: $\hat{y}_t = k + ab^t$


Пример кривых третьего класса:
Логистическая кривая и кривая Гомпертца. ($\hat{y}_t = k a^{8^t}$) ($\frac{1}{\hat{y}_t} = k + ab^t$) 

Рассмотрим метод последовательных разностей, помогающий при выборе кривых полиномиального типа. Этот метод применим при выполнении следующих предположений:
- уровни временного ряда могут быть представлены в виде суммы систематической составляющей и случайной компаненты, подчиненной нормальному закону распределения с мат ожиданием равным нулю и постоянной дисперсией.


Метод предполагает вычисление первой и второй разностей уровней ряда.
Для временного ряда $y_1, y_2, ..., y_n$ последовательные разности первого порядка определяются следующим образом: 
$$\triangle y_t = y_t - y_{t-1}, t = \overline{2, ..., n}$$
Последовательные разности второго порядка - разности от последовательной разности первого порядка:
$$\triangle^2 y_t = \triangle y_t - \triangle y_{t-1}, t = \overline{3, n}$$

Аналогично последовательные разности порядка $k \ge 3$ могут быть представлены в виде:
$$\triangle^k y_t = \triangle^{k-1} y_t - \triangle ^{k-1} y_{t-1}, t = \overline{k+1, n}$$

Расчёт ведётся до тех пор пока разности не станут, примерно, одинаковыми, и порядок разности принимается за степень выравнивающего полинома.

$$y' (x) = lim_{\triangle x \rightarrow 0} \frac{y(x + \triangle x) - y(x)}{\triangle x}$$
$$y' (x) \approx \frac{y(x + \triangle x) - y(x)}{\triangle x}$$
$$\triangle x = 1$$
$$y = x^3;y' = 3x^2; y'' = 6x; y''' = 6; y^{iv} = 0; ...$$

Замечание.
Перед тем как использовать метод последовательных разностей, необходимо проверить сглаживание временного ряда.
