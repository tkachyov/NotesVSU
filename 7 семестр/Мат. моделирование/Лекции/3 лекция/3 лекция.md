### Сглаживание с помощью взвешенных скользящих средних

При построении взвешенной скользящей средней на каждом активном участке значение центрального уровня заменяется на расчётное, определяемое по формуле средней арифметической взвешенной:
$$\hat{y}_t = \frac{\sum_{i=t-p}^{t+p} y_i \omega_i}{\sum_{i=t-p}^{t+p} \omega_i}, \omega \text{ - весовые коэффициенты}$$

Если $\omega_i = 1$  $\forall i \Rightarrow$   получаем формулу для простых скользящих средних.

Простая скользящая средняя учитывает все уровни ряда, входящие в активный участок с равными весами.
А взвешенная скользящая средняя приписывает каждому уровню вес, зависящий от удаления данного уровня до уровня стоящего в середине активного участка.

Это вызвано тем, что при простом скольжении средней выравнивание активного участка производится по прямой (полином 1-го порядка), а при сглаживании взвешенной скользящей средней выравнивание, используются полиномы более высших порядков.

Выравнивание с помощью взвешенной скользящей средней осуществляется следующим образом:
Для каждого активного участка подбирается полином следующего вида:
$$\hat{y}_t = a_0 + a_1t + a_2t^2 + ...$$
коэффициенты которого оцениваются с помощью метода наименьших квадратов (МНК).
При этом начало отсчёта (системы координат) переносится в середину активного участка.

Например.
Берём интервал длиной $l = 7$.
Рассмотрим следующие моменты времени $t: -3, -2, -1, 0, 1, 2, 3$.

Тогда сглаженным значением для уровня, стоящего в середине активного участка будет значение параметра $a_0$ подобранного полинома.


Неизвестные коэффициенты полинома второй степени оцениваются с помощью МНК, при этом находятся коэффициенты, минимизирующие следующий функционал:
$$Ф = \sum_{t = -2}^2 (y_{t-q_0-q_1}t - q_2 t^2)^2 \xrightarrow[\bar{a}]{}min$$
$\bar{a}$ - вектор параметров $a$ $(\bar{a} = (a_0, a_1, a_2))$.

$$\frac{\partial Q}{\partial x} = 0, i = \overline{1,2}$$


МНК позволяет получить эффективные и несмещённые оценки, которые могут быть получены при выполнении условий теоремы Гаусса-Маркова, которые предполагают отсутствие мультиколлинеарности регрессоров и нормально распределённые остатки, что на практике зачастую не выполняется. И возникает известная проблема в машинном обучении - **разброс-смещение**.
